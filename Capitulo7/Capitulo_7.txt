		-- booleanos 
			- un tipo de datos booleano puede tomar los valores NULL, FALSE y TRUE
				- estado VERDADERO (TRUE)
					- true
					- yes
					- on
					- 1
				- estado FALSO (FALSE)
					- false
					- no
					- off
					- 0
			+ select * from users;
			- agreguemos un tipo de datos booleano a la tabla de
				+ alter table users add user_on_line boolean;
			- Actualizamos
				+ update users set user_on_line = true where pk=1;
			- queremos buscar todos los registros que tienen el campo user_on_line con VERDADERO
				+ select * from users where user_on_line = true;
			-  Buscamos gistros en el mismo campo ahora buscar NULL
				+ select * from users where user_on_line is NULL;
		-- Numeric
				- PostgreSQL admite varios tipos de tipos de datos numéricos
					- integer or int4 (4-byte integer number).
					- bigint or int8 (8-byte integer number).
					- real (4-byte variable-precision, inexact with 6 decimal digit precision).
					- double precision (8-byte variable precision, inexact with 15 decimal digits precision).
					- numeric (precision, scale), donde la precisión de un numérico es el conteo total de dígitos	
			-- Integer
				- Postges puede convertir un numero con varios decimales y hacer un trunc value de acuerdo al tipo de datos
					+ select 1.123456789::integer as my_field;
					+ select 1.123456789::int4 as my_field;
					+ select 1.123456789::bigint as my_field;
					+ select 1.123456789::int8 as my_field;
			-- precisión fija
				- conversión a real
					+ select 1.123456789::real as my_field;
				- conversión doble precisión
					+ select 1.123456789::double precision as my_field;
			-- precisión arbitraria
				- conversión con precisión arbitraria
					+ select 1.123456789::numeric(10,1) as my_field;
						- 1.1
					+ select 1.123456789::numeric(10,5) as my_field;
						- 1.2346
					+ select 1.123456789::numeric(10,9) as my_field;
						- 1.123456789
				- decidimos cuántos dígitos debe tener la escala
					+ select 1.123456789::numeric(10,11) as my_field;
						- ERROR:  desbordamiento de campo numeric
						- tipo de datos se definió como un tipo numérico con un precisión igual a 10
					+ select 1.123456789::numeric(10,10) as my_field;
