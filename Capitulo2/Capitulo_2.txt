--- Administrar su clúster
	* PostgreSQL es un servicio que se puede iniciar, detener y, por supuesto, monitorear.
	* PostgreSQL incluye una herramienta "pg_ctl",  ayuda a administrar el clúster y los procesos en ejecución relacionados
	* pg_ctl acciones en un clúster, iniciarlo, reiniciarlo y detenerlo
		iniciar, detener y reiniciar
		estado actual
		cargar la configuración
		cambios de configuración
		replicación
	* pg_ctl status 
		para realizarlo dentro windowos, 
			ejecutamos el sistema de simbolo 
			direccionamos ala ruta (version/bin)
			ejecutamos el siguiente comando para ver el status "pg_ctl -D "C:\Program Files\PostgreSQL\16\data" status"
			el resultado es "pg_ctl: el servidor está en ejecución (PID: 4676)"
			Identificador de proceso (PID)
	* pg_ctl start
		si el comando anterior da otro resultado se debe ejecutar lo siguiente
			"pg_ctl -D "C:\Program Files\PostgreSQL\16\data" start"
	* pg_ctl stop
		Se puede detener el servicio con el siguiente comando 
			"pg_ctl -D "C:\Program Files\PostgreSQL\16\data" stop"
				como resultado "esperando que el servidor se detenga.... listo
				servidor detenido"
		* modo inteligente (smart -s) = esperará a que todos los clientes conectados se desconecten y solo entonces cerrará el clúster
		* modo rápido (fast -f) = esconectará inmediatamente a todos los clientes y apagará el servidor sin tener que esperar
		* modo inmediato (immediate -i) = anulará todos los procesos de PostgreSQL, incluidas las conexiones de los clientes, y apagará el clúster de manera sucia
			predeterminado=  modo rapido 
	* pg_ctl stop -m smart (smart -s/fast -f/immediate -i)
		sperará, imprimiendo un punto cada segundo hasta que todos los clientes se desconecten del servidor
		No se podra conectar a ningun cluster desde otro cliente, recibirar un mensaje de error
	* sudo -E -u postgres pg_ctl stop

--- Conexión al clúster
	Una vez que PostgreSQL se está ejecutando, espera las conexiones entrantes de la base de datos para servir
	bases de datos de plantilla: sirven como una base de datos común a la que puede conectarse en un clúster recién instalado
	Cuando inicializa el clúster (initdb) , PostgreSQL crea el diseño del sistema de archivos del directorio PGDATA y crea dos bd-plantillas, (template0 y template1)
	Para conectarse a una de las bases de datos, ya sea una plantilla o una definida por el usuario, debe necesita un cliente para conectar con. PostgreSQL
	- bases de datos de plantilla
		template1: creada cuando se inicializa el sistema
		template0: clon de la anterior, copia segura para reconstruir en caso de que sea dañado o eliminado accidentalmente.
